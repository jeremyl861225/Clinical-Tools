PESI 與 sPESI 的差別、以及 2019 ESC 怎麼用
◆ 兩者用途相同、變項不同。都是在血流動力學穩定的確診 PE 病人身上，找出低危、可考慮早期出院／門診治療的一群；不是用來抓「需要立刻再灌流」的高危（那要看休克／持續低血壓）。

◆ 原始 PESI（11 項，Aujesky 2005）→ 五個分級
・Class I–II（≤ 85 分）＝ 低危：30 天死亡率低，是門診／早期出院的候選（仍須無右心負荷、社會支持足）。
・Class III–V（≥ 86 分）＝ 較高危：住院治療，並依右心功能與 troponin 進一步分中低／中高危。

◆ 簡化 sPESI（6 項，Jiménez 2010）→ 二分：年齡 > 80、癌症、慢性心肺病（心衰或慢性肺病，合併只算 1 分）、脈搏 ≥ 110、SBP < 100、SaO₂ < 90%，各 1 分。
・0 分 ＝ 低危：30 天死亡率約 1.0%（95% CI 0.0–2.1%）。
・≥ 1 分 ＝ 高危：30 天死亡率約 10.9%（95% CI 8.5–13.2%）。
sPESI 把年齡改成「> 80」的二分、把心衰與慢性肺病併成「慢性心肺病」，並捨去性別、呼吸速率、體溫、意識——所以本頁勾了這些也不會影響 sPESI。

◆ 2019 ESC 的位置：穩定病人中，PESI Class III–V 或 sPESI ≥ 1 即歸為中危，再看右心功能（超音波／CT）與 troponin——兩者皆異常 → 中高危；僅其一 → 中低危。PESI I–II 或 sPESI 0 且無右心負荷、troponin 正常 → 低危，可考慮早期出院。血流動力學不穩者一律高危，與 PESI 無關。

⚠ 兩點提醒：
・低危≠可略過抗凝——低危指的是「死亡風險低、照護地點可下修」，抗凝仍要給。
・門診治療除了 sPESI 0，還要滿足無右心負荷、無需氧、疼痛可控、社會支持足、無其他住院理由（可對照 Hestia 準則）。
