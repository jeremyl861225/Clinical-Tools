SYNTAX Score

冠狀動脈解剖複雜度分級 · PCI 與 CABG 的選擇依據

分數三分位與意義
低 Low　≤ 22
解剖相對單純。PCI 與 CABG 的長期結果接近，多數情況 PCI 為合理選擇。
中 Intermediate　23–32
灰色地帶。需 Heart Team 個案討論；左主幹病灶在此區間 CABG 通常仍較有利。
高 High　≥ 33
解剖複雜。多支血管或左主幹病變時，CABG 明顯優於 PCI。
分數越高代表解剖越複雜、經皮處置越困難，PCI 的長期事件率相對 CABG 越差。SYNTAX 只評估解剖； SYNTAX II 再加入年齡、性別、肌酸酐廓清率、左心室射出分率、周邊血管疾病、慢性阻塞性肺病等臨床變項，用於個別化預測。
分數怎麼組成（原理）
三個層次相乘再相加
  • 節段權重：依該節段供應左心室血流的比重給權重，並隨左右優勢型（dominance）而不同。
  • 阻塞程度倍率：狹窄 50–99%（obstructive）× 2；完全阻塞 100%（occluded）× 5。
  • 不良特徵加分：完全阻塞的次特徵（阻塞時間 > 3 個月、鈍頭殘端、橋接側支、遠端無法顯影、分支受累）、 三分岔、分岔（依 Medina 型別）、主動脈開口病灶、嚴重扭曲、病灶長度 > 20 mm、嚴重鈣化、血栓、瀰漫性病變／小血管。 各項點數本頁不列（見上方警語）。

用在血管重建的選擇
左主幹病灶 Left main
  • SYNTAX ≤ 22：PCI 與 CABG 皆合理（個體資料統合分析顯示 5 年死亡率無顯著差異）。
  • SYNTAX 23–32：兩者皆可考慮，需 Heart Team 討論；合併糖尿病或複雜分岔時偏向 CABG。
  • SYNTAX ≥ 33：CABG 為首選。
三支血管病變 Three-vessel disease
  • 合併糖尿病或 SYNTAX ≥ 23 → CABG 優於 PCI（存活與再次血管重建皆較佳）。
  • 左心室功能下降者 CABG 益處更明顯。
  • SYNTAX ≤ 22 且解剖適合、無糖尿病者，PCI 為合理替代。
在 ACS 情境下的但書
急性期不要被 SYNTAX 綁住。STEMI 的首要任務是立即打通犯罪血管；SYNTAX 與 Heart Team 討論是用來決定 後續完整血運重建的方式，而不是延後急性再灌流的理由。心因性休克或機械併發症時， 直接依「何時需要緊急 CABG」處理（見急性冠心症頁的治療分頁）。
