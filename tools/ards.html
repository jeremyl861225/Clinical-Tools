Respiratory Failure Diagnostic Tool

ARDS 診斷與分級

急性呼吸窘迫症候群 · New Global Definition 2024（含 Berlin 2012 對照）
版本提醒 Version

本頁採 2024 新全球定義（Matthay 等，Am J Respir Crit Care Med 2024;209(1):37-47），這是 Berlin 2012 以來最大的一次改版。四項實質變動：

①納入未插管者——高流量鼻導管 ≥30 L/min，或 NIV／CPAP 且吐氣末壓 ≥5 cmH₂O；
②可用 SpO₂/FiO₂ 取代 PaO₂/FiO₂（限 SpO₂ ≤97%）；
③超音波納入影像判準；
④另立資源受限地區的簡化判準（不要求 PEEP 與最低氧流速）。
新定義自身聲明：其可行性、信度與預後效度仍待前瞻驗證。Berlin 定義並未被撤銷，多數臨床試驗的收案條件仍寫 Berlin，判讀文獻時須留意兩者不等價。
完整判準、FiO₂ 估算、海拔校正與 Berlin 對照 Definitions
◆ 所有類別共通的三項判準（缺一不可）：
・危險因子與水腫來源：由急性誘發因子引起（肺炎、非肺部感染、外傷、輸血、燒傷、吸入、休克）。肺水腫不得主要來自心因性肺水腫／體液過多，低血氧也不得主要來自肺塌陷；但若同時存在 ARDS 的誘發因子，仍可在這些情況下診斷 ARDS。
・時間：於誘發因子發生、或呼吸症狀新發／惡化後的一週內急性發生或惡化。
・胸部影像：X 光或電腦斷層的雙側浸潤，或超音波的雙側 B 線與／或實變，且無法完全以肋膜積液、肺塌陷或結節／腫塊解釋。超音波操作者須受過辨識雙側肺通氣喪失的訓練。

◆ 三個類別的氧合判準：
・未插管 ARDS：PaO₂/FiO₂ ≤300 mmHg 或 SpO₂/FiO₂ ≤315（限 SpO₂ ≤97%），且在 HFNO 流速 ≥30 L/min 或 NIV／CPAP 吐氣末壓 ≥5 cmH₂O 之下。未插管 ARDS 不再細分嚴重度。
・插管 ARDS：輕度 200<P/F≤300 或 235<S/F≤315；中度 100<P/F≤200 或 148<S/F≤235；重度 P/F≤100 或 S/F≤148。所有嚴重度都要求 PEEP ≥5 cmH₂O。
・資源受限地區：SpO₂/FiO₂ ≤315（限 SpO₂ ≤97%），不要求 PEEP，也不要求最低氧流速或特定呼吸支持裝置。適用於動脈血氣、HFNO、NIV 或呼吸器不易取得之處。
病人可在病程中於不同類別間移動。

◆ FiO₂ 估算（原文附註）：使用一般氧氣裝置而無法得知確切 FiO₂ 時，估算 FiO₂ = 0.21 + 0.03 × 氧流速（L/min）。本頁「以流速估算」選項即用此式。

◆ 測量條件：血氣與血氧測量應在病人安靜休息時，且距離變換姿勢、調整 FiO₂ 或流速至少 30 分鐘後進行。使用血氧計時須確認波形與探頭位置良好。SpO₂ >97% 時 S/F 比值無效。懷疑血紅素異常（變性血紅素、碳氧血紅素）時不建議用血氧計診斷。

◆ 海拔校正：海拔 >1,000 公尺時，比值須乘上 大氣壓/760。本頁提供海拔輸入，並以標準大氣模型估算大氣壓（原文只給校正式，未指定壓力來源；有實測值時請直接以實測大氣壓判讀）。

◆ 與 Berlin 2012 的差異：Berlin 要求所有病人都在 PEEP ≥5 cmH₂O 之下（形式上，未接受正壓者無法診斷 ARDS）、只認 X 光與電腦斷層、只用 PaO₂/FiO₂、且分輕／中／重三級。新定義保留了「一週內、雙側浸潤、非心因性」的骨幹，擴充的是誰能被診斷與用什麼測量。
